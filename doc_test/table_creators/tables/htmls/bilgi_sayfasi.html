Wastewater Source
Only domestic wastewater from toilets, sinks, shower, dishwash and laundry.
Wastewater should not contain any chemicals which is harmful for the bacteria inside wastewater.
Rainwater and swimming pool water which may contain chlorine and chemicals should not be allowed into the ST system. Fat, Oil and Grease (FOG) should not be allowed into the system.
Wastewater from kitchens definitely should pass through oil traps in kitchens.
